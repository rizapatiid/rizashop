# 🛒 TOKORIZA Project

Aplikasi **Marketplace berbasis Laravel** dengan sistem **multi-role** untuk **Seller (Admin)** dan **Pelanggan (User)**.  
Project ini masih dalam tahap **pengembangan aktif** dan akan terus dikembangkan dari sisi fitur dan UI.

---

## 🚀 Status Pengembangan
- ✅ Seller (Admin)
- ✅ Pelanggan (User)
- ⏳ Admin Utama (rencana)
- ⏳ Live Chat Customer Service (rencana)
- ⏳ Custom UI (belum dicustom ini saya utaman sistemnya berjalan lancar dahulu baru kita lanjut custom ui)
